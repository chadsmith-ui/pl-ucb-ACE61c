# Datapath question builder (instructors only)

Builds the `<pl-riscv-datapath>` tag for a new question. Do not add this question to an assessment.

1. Preview this question and follow the five steps: instruction (optional preset), initial state, answer key, optional value boxes, export.
2. Copy the tag and paste it into the `question.html` of your new question.
3. To edit an existing problem, use "Edit an existing problem" in step 1 and paste that question's tag.
