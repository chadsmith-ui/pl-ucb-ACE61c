Consider the single-cycle datapath and the instruction lw x5, 0(x6).

Focus on the bold wires going into the write-back mux. Grey means "not set yet": click a wire to turn it red (carries the value this instruction uses) or black (does not). Some wires start with a value that may be wrong, so check every bold wire. The thin red wires are given and cannot be changed. Enter the WBSel value in hexadecimal in the gray box.
